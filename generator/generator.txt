Implementation:

    Just stuff like "<!-- Inherits: path/to/blank.md -->", or "<!-- Depricated -->"
    Or even "<!-- Property: Transform/Name String description description description -->"
    Python should be able to parse these special comment flags and convert them into a workable data format
    On export, it should be able to create these flags again if the object has been editted, and 
    generate correct markdown to both convey the information, but also follow the format that has become convention
